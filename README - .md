# SWRFussSWGD

See Doc folder for other readme files.



See System folder for the version file, which discusses changes made along the way of combining SWRFuss 1.43, SWL 1.6.1, SWGD (unknown version dated 5.21.17), and SWGD help files (https://web.archive.org/web/20220629061010/http://swgd.genesismuds.com/).



This project is an attempt to merge the above code bases, with the assistance of Claude AI.  Also included in the files, is a manual of sorts which discusses the structure of SWR, explanation of portions of code, gaming aspects.



Take this project with a grain of salt as I'm not an expert coder.  But this has been a good learning experience about how SWR files work together.  And it plays closely (still testing porting of subclasses etc), to the original SWL and SWGD code bases which only had their Src files provided.
